# UHSxPathology

Tools, scripts, and utilities supporting Pathology IT at University Hospitals Sussex.

This repository provides a central location for technical resources relating to laboratory systems, automation, monitoring, integration, and operational support.

## Scope

- LIMS and laboratory systems
- PowerShell and automation
- System monitoring and diagnostics
- Integration and data processing
- Supporting documentation

> **Note:** All code should be reviewed and tested before production use. Patient-identifiable or confidential information must not be committed to this repository.
